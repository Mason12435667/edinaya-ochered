# Единая очередь: настраиваемая версия

Веб-система обработки обращений и заявок для небольших служб поддержки.
Публичная ветка предназначена для установки **с собственными данными** и
настройками каждой организации. Она не является готовым SaaS-продуктом.

## Возможности

- Единая очередь заявок, статусы, исполнители, приоритеты
- Веб-интерфейс, история переписки и вложения
- Роли, пользовательские настройки и статистика
- Коннектор WhatsApp Web для прототипирования и внутренних тестов
- Настраиваемое меню обращений, русская и казахская локализация

## Настройка

Скопируйте `config/company.example.json` в `config/company.json` и задайте
собственное название организации, приветствия, категории и вопросы.
`config/company.json` не публикуется в Git. Переменная `QUEUE_GENERIC_CONFIG`
позволяет использовать конфигурацию вне репозитория. Универсальный профиль
включён по умолчанию: `QUEUE_PROFILE=generic`.

Настройки окружения начинайте с `.env.example`. Секреты, данные пользователей,
архивы сессий и резервные копии не должны попадать в репозиторий.

## Часовой пояс

Рабочее время (смены, отчёты, отметки времени) считается в поясе из `.env`:
`QUEUE_TIMEZONE` (IANA-имя, например `Europe/Berlin`) или `QUEUE_UTC_OFFSET_HOURS`
(по умолчанию `5`).

## База знаний из Google Таблицы (необязательно)

Укажите в `QUEUE_INSTRUCTION_SOURCE_URL` ссылку на собственную таблицу с
инструкциями, доступную по ссылке для просмотра. Данные конкретной компании в
проект не встроены.

## Ограничения

Коннектор WhatsApp Web не является официальным WhatsApp Business Platform API.
Его работу и соответствие правилам сервиса следует оценивать отдельно перед
коммерческим применением.

## Проверка перед публикацией

```bash
bash scripts/verify_snapshot.sh .
```

Собственные приватные маркеры (IP серверов, имена компьютеров, названия
организаций) можно перечислить в файле `.private-markers` по одному регулярному
выражению на строку. Файл не попадает в Git, а скрипт заблокирует публикацию,
если найдёт совпадение.
