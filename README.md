# Единая очередь

**Единая очередь** — внутренняя система обработки технических обращений из мессенджеров с единой очередью заявок, статусами, категориями, исполнителями и рабочим веб-интерфейсом.

> Публичный GitHub-релиз: **v2026.10.0**  
> Срез проекта: **2 октября 2026**

## Что умеет система

- принимает обращения из WhatsApp через QR/LocalAuth-коннектор;
- создаёт и ведёт заявки с категориями, статусами и приоритетами;
- поддерживает ответы сотрудников и привязку уточнений к исходному обращению;
- показывает личные и групповые чаты в рабочем интерфейсе;
- обрабатывает текст, изображения, видео и голосовые сообщения;
- поддерживает автоответы, обязательный выбор категории и пошаговый сбор данных;
- хранит историю заявок и действий;
- поддерживает роли сотрудников и административные настройки;
- содержит рабочие инструменты для перевозок/транзита и связанных технических сценариев;
- имеет светлую/тёмную тему, поиск, избранные чаты и уведомления;
- рассчитана на Ubuntu-сервер и работу через systemd.

## Архитектура

```text
WhatsApp Web
    │
    ▼
whatsapp_qr_connector.js
    │
    ▼
Python backend / handlers
    │
    ├── ticketing / workflow / business logic
    ├── chat state / realtime
    ├── media / uploads
    └── admin / auth / reporting
    │
    ▼
SQLite + Web UI
```

Основной рабочий канал в этом релизе — **WhatsApp**. Экспериментальные и отдельные Telegram-автоматизации в публичный снимок не добавляются автоматически.

## Публичная версия и внутренние хотфиксы

Во время разработки использовалась внутренняя линейка `1.00.6.xxx` и отдельные точечные патчи `vN`. Они были удобны для безопасного обновления рабочего сервера, но для GitHub слишком дробные.

Начиная с этого снимка публичные версии используют **CalVer**:

```text
v2026.10.0
│    │  └─ номер значимого обновления в месяце
│    └──── месяц
└───────── год
```

Мелкие серверные исправления не обязаны получать отдельный GitHub Release. Они накапливаются до следующего значимого среза.

## Безопасность публикации

В репозиторий **не должны попадать**:

- `.env` и реальные токены;
- `/etc/edinaya-ochered/secrets.env`;
- `tickets.db` и другие рабочие БД;
- WhatsApp LocalAuth/QR-сессии;
- реальные Google Sheets ID/URL и service-account ключи;
- загруженные пользователями медиа;
- журналы;
- резервные копии;
- персональные данные сотрудников и пользователей.

Перед публикацией снимок можно проверить командой:

```bash
bash scripts/verify_snapshot.sh .
```

## Установка

Публичный снимок является исходным кодом проекта и не содержит рабочую базу, секреты, реальные Google Sheets ID или авторизованную WhatsApp-сессию.

Текущая рабочая ветка тестировалась на **Python 3.12** и **Node.js 22**. Коннектор в `package.json` заявляет Node.js 18+.

```bash
npm ci
```

Основная Python-часть опирается преимущественно на стандартную библиотеку. Дополнительные интеграции устанавливаются отдельно:

```bash
# Google Sheets read/write
pip install -r requirements-google.txt

# Транскрибация голосовых сообщений
pip install -r requirements-voice.txt
```

Скопируйте значения из `.env.example` в собственную конфигурацию окружения и задайте как минимум длинный случайный `WEBHOOK_TOKEN`. Файл `.env` в Git не добавляется.
