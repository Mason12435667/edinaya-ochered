# Единая очередь

**Версия:** 1.00.3 Stable  
**Статус:** завершённый проект, поддерживается в maintenance-режиме

«Единая очередь» — внутренняя web-система для приёма и обработки обращений из WhatsApp с переводом сообщений в структурированные заявки.

Проект создавался как рабочая система Service Desk: сотрудники получают сообщения, ведут переписку, создают и обрабатывают заявки, меняют статусы, работают с вложениями и используют административные инструменты из одного интерфейса.

## Возможности

- подключение рабочего WhatsApp через `whatsapp-web.js`;
- личные и групповые чаты внутри web-интерфейса;
- создание заявок из входящих сообщений;
- статусы, приоритеты, назначение сотрудника и история изменений;
- автоответы и настраиваемое меню обращений;
- вложения, изображения, ответы, пересылка и реакции;
- транскрибация голосовых сообщений через `faster-whisper`;
- поиск по чатам и заявкам;
- административная панель;
- уведомления и контроль состояния системы;
- SQLite-хранилище;
- резервное копирование и восстановление;
- отдельное хранение секретов и WhatsApp-сессии;
- systemd-сервисы и Nginx для Ubuntu.

```text

   |---- workflow / reliability / productivity modules
   |
```

## Запуск для разработки

Требования:

- Python 3.12+
- Node.js 18+
- npm

Установить Node.js-зависимости:

```bash
npm ci
```

Основной Python backend не требует сторонних библиотек.

Для транскрибации голосовых сообщений:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements-voice.txt
```

Примеры конфигурации находятся в `server/queue.env.example` и `secrets.env.example`. Реальные токены и пароли не должны храниться в репозитории.

## Ubuntu

В `server/` находятся скрипты первой установки, обновления, проверки, backup/restore, systemd unit-файлы и пример конфигурации Nginx.

Рабочая установка использует отдельные каталоги:

```text
/opt/edinaya-ochered
/var/lib/edinaya-ochered
/etc/edinaya-ochered
/var/backups/edinaya-ochered
```

Исходный код не должен содержать рабочую SQLite-базу, WhatsApp-сессию или секреты.

## Безопасность публичной версии

Эта копия подготовлена для портфолио:

- реальные токены и пароли не включены;
- WhatsApp LocalAuth не включён;
- рабочая база данных не включена;
- пользовательские сообщения, фото и вложения не включены;
- внутренние телефоны, ссылки и инструкции заменены демонстрационными данными;
- `.gitignore` исключает runtime-данные, кеши, секреты и резервные архивы.

`instruction_data.json` содержит **демонстрационные обезличенные данные** и не является рабочей инструкцией организации.
