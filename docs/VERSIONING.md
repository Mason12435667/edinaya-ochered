# Versioning policy

Public GitHub versions use CalVer: `vYYYY.MM.N`.

Production may still receive emergency hotfixes between public releases. Those fixes should be accumulated under an `Unreleased` section and folded into the next public version instead of creating a new GitHub Release for every small change.

Examples:

- `v2026.10.0` — first consolidated October snapshot;
- `v2026.10.1` — a meaningful second October update;
- `v2026.11.0` — first November snapshot.
