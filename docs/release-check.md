# Проверка перед выкаткой

Тесты и сравнение версий работают на искусственных данных. Этот список проверяет то, что
они проверить не могут: настоящий WhatsApp-коннектор и настоящую переписку. Его нужно
пройти на отдельном номере, прежде чем обновлять рабочую систему.

## Подготовка

- [ ] Отдельный номер WhatsApp и отдельная папка данных (`QUEUE_DATA_DIR`), не рабочие.
- [ ] Если используется копия рабочей базы, это копия: исходный файл не открывать.
- [ ] Записана версия, которая работала до обновления, чтобы было куда вернуться.
- [ ] Журнал сервиса открыт и виден во время проверки.

Старая база обновляется при первом запуске. После этого прежняя версия программы может с ней
не работать, поэтому резервную копию делайте до запуска.

## Коннектор

- [ ] Коннектор подключается, индикатор на сайте показывает «Подключён».
- [ ] После остановки коннектора индикатор и уведомления показывают проблему.
- [ ] После повторного подключения предупреждение исчезает само.

## Бот

- [ ] Новый контакт получает выбор языка, затем запрос подразделения и должности, затем меню.
- [ ] Заявка создаётся полностью: категория, описание, команда завершения.
- [ ] Пункт 8 показывает активные заявки.
- [ ] Контакт, добавленный вручную, не получает автоответов.
- [ ] При выключенном автоответчике бот молчит, а сообщения сохраняются.
- [ ] Сообщение, оставшееся без ответа 30 минут, получает меню.

## Чаты

- [ ] Списки чатов и групп открываются, имена и аватары на месте.
- [ ] Нет двойных карточек одного человека (`@lid` и номер телефона).
- [ ] Текст, фото, голосовое, видео и документ приходят и открываются.
- [ ] То же отправляется с сайта, в том числе файл больше нескольких мегабайт.
- [ ] Фото и документ с сайта доходят без ошибки `Data passed to getter must include an id property`.
- [ ] Текст, фото и документ пересылаются в другой чат, получатель видит пометку «Пересланное».
- [ ] Удалённое в WhatsApp сообщение показано как удалённое, в том числе в списке слева.
- [ ] Реакции, ответы на сообщения и упоминания в группе отображаются.
- [ ] Пересылка из личного чата в группу и обратно. Первое раньше не работало.
- [ ] Отложенное сообщение уходит вовремя, отменённое не уходит.

## Заявки и сотрудники

- [ ] Смена статуса, приоритета и исполнителя, закрытие с комментарием.
- [ ] Пользователь получает сообщение о закрытии заявки.
- [ ] Два сотрудника меняют одну заявку: второй видит сообщение о конфликте.
- [ ] Массовое изменение нескольких заявок.
- [ ] Диалог, занятый одним сотрудником, у другого открывается только для чтения.
- [ ] Вложения видны на странице заявки.

## Админка

- [ ] Открываются все разделы, включая «Система», «Надёжность», «Журнал» и «Контакты».
- [ ] Резервная копия создаётся и проходит проверку.
- [ ] Режим обслуживания блокирует сотрудников, но не администратора, и выключается.
- [ ] Самостоятельная регистрация выключена, ссылок на неё нет.

## Журнал

Смотрите журнал всё время проверки и ещё день-два после неё. После сужения `except` ошибка
в коде теперь видна, а раньше превращалась в пустой результат. Поэтому новая трассировка —
это находка, а не обязательно новая поломка.

- [ ] Нет трассировок `Traceback`.
- [ ] Нет повторяющихся строк `[db141]` с ошибками и `database is locked`.
- [ ] Нет обрывов соединения у коннектора.

Для каждой найденной ошибки сохраните трассировку и что в этот момент делали: этого
достаточно, чтобы найти причину.

## Если что-то пошло не так

Остановите новую версию, верните записанную версию и резервную копию базы. Не исправляйте
рабочую базу вручную.
