# v2026.10.0 — Consolidated October 2026 release

Это первый консолидированный публичный срез «Единой очереди» после серии внутренних production-hotfix'ов.

## Главное

- актуальная рабочая архитектура WhatsApp → backend → единая очередь → web UI;
- объединены исправления диалогов, категорий, автоответов и realtime;
- улучшена стабильность WhatsApp-коннектора;
- улучшена работа с медиа и пользовательскими профилями;
- устранён ряд дублей WhatsApp-чатов (`@lid` / `@c.us`);
- улучшены уведомления и административные инструменты;
- актуализирована совместимость с WhatsApp Web/Chromium.

## Что специально не входит в публичный релиз

- рабочая SQLite-база;
- WhatsApp LocalAuth/QR-сессия;
- `.env` и серверные секреты;
- пользовательские медиа и вложения;
- логи и резервные копии;
- внутренние данные компании;
- отдельные экспериментальные Telegram/KEDEN-утилиты, если они не являются частью основной `/opt/edinaya-ochered`.

## Версионирование

Вместо публикации десятков `1.00.6.xxx` GitHub использует крупные CalVer-релизы. История внутренних исправлений сохранена в `CHANGELOG.md` по датам и функциональным этапам.
