# Changelog

История ниже описывает **крупные этапы**, а не каждый внутренний hotfix. В рабочей среде между этими этапами выпускались точечные `1.00.6.xxx` и `vN`-патчи; в GitHub они объединяются в более понятные релизы.

## [v2026.10.0] — 2026-10-02

Первый консолидированный GitHub-срез текущей рабочей ветки.

### 2026-10-02 — совместимость WhatsApp Web

- коннектор переведён на нативный User-Agent текущего Chromium вместо устаревшего UA, который мог подставляться библиотекой;
- сохранена существующая LocalAuth/QR-сессия;
- изменение не требует удаления авторизации WhatsApp.

### 2026-10-01 — медиа, профили и устранение дублей

- ускорены повторные попытки загрузки медиа;
- добавлен более гибкий разбор поста/должности пользователя;
- исправлено завершение заявки командами «Готово» / «Дайын»;
- устранены дубли личных WhatsApp-чатов, возникавшие из-за параллельных `@lid` и `@c.us` идентификаторов;
- добавлено схлопывание уже видимых дублей в live chat state;
- улучшено объединение истории уже существующих чатов;
- доработаны браузерные уведомления и элементы управления ботом в длинных чатах.

### 2026-09-30 — крупная стабилизация диалогов и производительности

- переработана обработка диалога WhatsApp и обязательного выбора категории;
- добавлено восстановление зависшего/устаревшего меню;
- улучшена обработка ответов вида `2. Перевозка`, многострочных данных и команды «вся инфа»;
- цифры меню получили приоритет над устаревшим контекстом, без ошибочного распознавания длинных номеров как пунктов меню;
- автоответы защищены от дублей между live и recovery-путями;
- ускорен горячий путь входящего сообщения → интерфейс → автоответ;
- тяжёлые фоновые операции отделены от realtime-обработки;
- улучшен старт коннектора и восстановление после перезагрузки WhatsApp Web;
- добавлены проверки реального WWebJS bridge, а не только статуса `CONNECTED`;
- снижена конкуренция фоновой синхронизации контактов, групп, аватаров и звонков;
- исправлялись блокировки SQLite (`database is locked`) и медленные участки;
- добавлены технические сценарии проверки KEDEN/ТД и восстановление состояния диалога;
- администраторские элементы управления ботом стали доступнее в интерфейсе.

Внутренние серверные номера этого этапа включали, среди прочего, `1.00.6.137–1.00.6.141`, после чего часть доработок продолжила жить как функциональные патчи без нового публичного релиза.

## Правило будущих GitHub-релизов

На GitHub публикуются **крупные срезы**, а не каждый production-hotfix.

Пример:

- `v2026.10.0` — текущий октябрьский консолидированный срез;
- `v2026.10.1` — только если в октябре будет заметный набор исправлений/функций;
- `v2026.11.0` — следующий крупный ноябрьский срез.

Точечный серверный фикс можно задокументировать в `Unreleased`, не создавая отдельный Release.
