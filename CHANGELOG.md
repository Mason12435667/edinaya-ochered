# История универсальной версии

## v143

- Удалена вся отраслевая логика прежнего внедрения: специальные категории, шаблоны
  распознавания номеров, подменю и тексты, связанные с конкретной сферой работы
- Из таблицы заявок убраны отраслевые колонки; заявка хранит только общие поля
- Профиль пользователя теперь «Подразделение / Должность»
- Ручная заявка в веб-интерфейсе стала универсальной (без привязки к мессенджеру)
- Часовой пояс настраивается через `QUEUE_TIMEZONE` / `QUEUE_UTC_OFFSET_HOURS`
- Удалён неиспользуемый модуль записи в Google Sheets
- Проверочный скрипт больше не содержит приватных адресов; свои маркеры задаются
  в git-игнорируемом `.private-markers`

## v135

- Сохранена универсальная синхронизация базы знаний
